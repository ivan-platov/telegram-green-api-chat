# Фон чата

`max-space-pattern.svg` — статический фон, наблюдавшийся и экспортированный из авторизованного MAX Web 21.10.2026 для воспроизведения визуального прототипа по тестовому заданию.

Источник: https://web.max.ru/_app/immutable/assets/pattern_space.aFb4MW9l.svg

## Иконки

`icons/*.svg` — отдельные SVG из [Lucide](https://lucide.dev/), зафиксированные по [ревизии c29c276](https://github.com/lucide-icons/lucide/tree/c29c276f16590cf017126671535ad8c792be64d8/icons).
Лицензия и уведомления об авторских правах сохранены в [icons/LICENSE](icons/LICENSE).

Компоненты импортируют конкретный SVG и выводят его одним декоративным `span.icon` через CSS `mask-image`: так SVG сохраняет цвет `currentColor`, включая состояния доставки, ошибки и отключённой кнопки. Подписи действий и статусов остаются на кнопках и метаданных для вспомогательных технологий. Встроенных SVG и шрифтовых символов вместо иконок нет.

Личные аватары, вложения, данные аккаунта и JavaScript MAX в приложение не переносились. Авторство оформления MAX не приписывается этому проекту.
